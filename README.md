## 本地启动

```bash
npm install
npm run dev
```

默认访问地址：`http://localhost:3000`

## 生产构建

```bash
npm run build
npm start
```

## 资源目录

- 证书 PDF：`public/certificates/`
- 简历 PDF：`public/resume/resume.pdf`
- 站点图标：`public/favicon.svg`

## 代码入口

- 页面结构：`src/app/`
- 页面文案数据：`src/lib/site-data.ts`
- GitHub Actions：`.github/workflows/`
